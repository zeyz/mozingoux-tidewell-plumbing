# Tidewell Plumbing

A fictional, independent MozingoUX portfolio concept. No affiliation with a real business. All prices and contact information are illustrative.

## Run

Serve this folder with `python3 -m http.server 8000` or any static server. No build or dependencies. GitHub Pages can publish the repository root on `main`. All asset paths are relative.

## Features

Responsive layouts, keyboard accessible navigation, native expandable FAQs, labeled validated demo form with no transmission or storage, reduced-motion support, local image assets.

## Imagery

Illustrative photography from Unsplash, downloaded for local serving. Source: https://images.unsplash.com/photo-1585704032915-c3400ca199e7. Photography does not depict the fictional business or establish affiliation.

## Contact form

This demonstration provides a local confirmation only. It does not send email or book appointments. Use fictional information.
